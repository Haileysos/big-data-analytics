###### 학습목표 : 빅데이터 처리를 위한 핵심 기술 스택 구조를 이해하고, 올바른 데이터 분석을 수행하기 위해 필수적인 통계적 기초 개념과 확률 분포를 학습한다.  

# 학습 범위 및 기술 기초  
빅데이터 분석을 위한 핵심 기술 스펙트럼  
- 고차원 데이터 (High-dimensional)  
  > 특징 : 변수가 매우 많음  
  > 도전 : 차원의 저주  
  > 해결 : 특성 선택, 차원 축소  
  > 예시 : 유전체 데이터 분석  

- 그래프 & 네트워크 (Graph Analysis)
  > 특징 : 노드와 엣지로 관계 표현    
  > 알고리즘 : PageRank, 커뮤니티 탐지   
  > 응용 : SNS분석, 추천 시스템, 이상 탐지  
  > 예시 : 소셜 네트워크 영향력  

- 스트리밍 처리 (Real-time algo)
  > 특징 : 무한히 들어오는 데이터 처리  
  > 제약 : 메모리 제한, One-pass 처리  
  > 기법 : 슬라이딩 윈도우, 근사 알고리즘  
  > 예시 : 실시간 거래 모니터링  

- 선형대수 & 최적화 (Optimization)  
  > 기초 : 행렬 분해, 고유값, 벡터 공간  
  > 응용 : 머신러닝 모델 최적화 (Loss 최소화)  
  > 알고리즘 : 경사 하강법  
  > 예시 : 추천 시스템 행렬 분해
